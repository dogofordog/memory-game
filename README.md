# Memory Game

Игра на поиск пар. Учебный проект RS School.

## О проекте

На поле 16 карточек с 8 разными изображениями — каждое встречается дважды. Игрок открывает по две карточки за ход. Совпавшие остаются открытыми, несовпавшие закрываются через секунду. Цель — найти все 8 пар за минимальное число ходов.

Результаты сохраняются в localStorage и отображаются в таблице лидеров (топ-10).

## Функциональность

- Генерация всей разметки через JavaScript (в `index.html` только тег `<script>`).
- Случайное перемешивание карточек (алгоритм Фишера–Йетса).
- Счётчики ходов и найденных пар.
- Модальное окно победы с итоговым числом ходов.
- Таблица лидеров (топ-10).
- Сохранение результатов между сессиями через `localStorage`.
- Закрытие модальных окон: кнопка, клик по фону, Escape.

## Технологии

- HTML
- CSS (Grid, адаптивная вёрстка)
- JavaScript (vanilla, без библиотек и фреймворков)
